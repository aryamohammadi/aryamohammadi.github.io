# My Portfolio Website

This is my personal portfolio website that I built while studying Mathematics and Computer Science at UC San Diego. It showcases my projects, skills, and experience as I apply for internships and full-time opportunities.

## About This Project

I created this portfolio from scratch to have a professional online presence for internship applications. It features my key projects, technical skills, work experience, and a photo gallery. The site includes a dynamic typing animation on the homepage and is fully responsive across all devices.

## Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile viewing
- **Dynamic Typing Animation** - Interactive homepage using Typed.js library
- **Project Showcases** - Detailed project descriptions with live demo links
- **Professional Experience** - Work history and technical skills
- **Contact Integration** - Easy ways for recruiters and employers to reach out
- **Photo Gallery** - Personal photos to add personality to the portfolio

## Technology Stack

- **HTML5** - Semantic markup and structure
- **Tailwind CSS** - Utility-first CSS framework for styling
- **Vanilla JavaScript** - Dynamic functionality and component loading
- **Typed.js** - Smooth typing animation effects
- **GitHub Pages** - Free static site hosting

## Local Development

To run this portfolio locally:

1. Clone this repository to your local machine
2. Open `index.html` in your web browser
3. That's it - no build process required

The site uses vanilla HTML, CSS, and JavaScript, so it runs directly in the browser without any compilation or server setup.

## Deployment

This portfolio is deployed using GitHub Pages, which automatically updates whenever changes are pushed to the main branch. The deployment process is seamless and requires no additional configuration.
